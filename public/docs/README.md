### Estrutura Recomendada dos Modelos

#### Currículo Moderno (PDF)
- Design atrativo com cores sutis
- Layout em colunas
- Ícones para seções
- Tipografia moderna
- Espaços bem distribuídos

#### Currículo Simples (DOCX)
- Layout tradicional
- Fácil edição
- Formato conservador
- Adequado para impressão
- Compatível com ATS (Applicant Tracking Systems)
